## Projects

### [NetPriority](https://github.com/Ossama53/NetPriority)

A Windows tool that lets you designate a specific application, game, or download as the "priority," temporarily blocking other applications from accessing the internet.

### [PacketWatch](https://github.com/Bandar12123/PacketWatch)

This tool is designed to monitor packets in the network with an easy and understandable UI window for users to detect and watch the packets coming through and leaving their device.

### [V6O](https://github.com/m7md-d/V6O)

The V6O project is based on making a V60-style drip machine.

### [SDCS](https://github.com/m7md-d/SDCS)

**Smart Drone Controller System (SDCS)** is a system that lets a user draw on
a web page using a drone controller. The controller is connected to an Arduino,
and the drone's movement is translated into drawing on the UI interface.
